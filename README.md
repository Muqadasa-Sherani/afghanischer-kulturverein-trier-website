# Afghanischer Kulturverein Trier e.V. – Website

Website for the Afghanischer Kulturverein Trier e.V., a community association founded in 2023 that connects Afghan and German culture: *two cultures, one Home*.

The site serves Afghans who are new to Germany or already living here, with news, event information and ways to get involved.

> **Status:** in development

## Features (planned)

- News: upcoming and past events
- Team page with board and community members
- Photo and video archive
- Contact form and membership application
- Donation page (bank transfer with GiroCode QR, optional PayPal)
- Four languages: German, English, Dari and Pashto, with right-to-left layout
- Read-aloud button and audio for people who cannot read
- Mobile-first, accessible design
- Browser-based editor so volunteers can publish posts without coding
- Privacy-friendly: no cookies, self-hosted fonts, YouTube loads only after a click

## Tech stack

- [Astro](https://astro.build): static site generator
- [Sveltia CMS](https://github.com/sveltia/sveltia-cms): Git-based content editor
- Cloudflare Pages: hosting
